# Java Data Analyzer

## Overview

This project is a Java-based data analysis application that processes numeric datasets from text files and calculates key statistical metrics.

The application reads data line by line, allowing it to handle larger files efficiently without loading the entire dataset into memory.

## Key Features

- File-based data analysis
- Calculates count, mean, standard deviation, and RMS
- Efficient single-pass processing
- JavaFX graphical user interface
- Export results to a `.txt` file
- Error logging for debugging
- Unit testing with JUnit

## Technologies Used

- Java
- JavaFX
- JUnit 5
- Gradle
- IntelliJ IDEA
- File I/O
- Welford’s Algorithm

## How to Run

1. Clone the repository
2. Open the project in IntelliJ IDEA
3. Make sure the JavaFX SDK is configured if needed
4. Run the main application file
5. Select a `.txt` file containing numeric data
6. View the calculated statistics
7. Export the results if needed

## Example Output

The application displays:

- Count
- Mean
- Standard Deviation
- RMS
